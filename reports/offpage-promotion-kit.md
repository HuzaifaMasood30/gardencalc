# GardenCalc off-page promotion kit

Prepared 2026-10-26. Everything here is copy-paste ready. The rule for all of it:
**help first, link second.** One genuine answer with one link beats fifty dropped
links, and bought or spammed links can get the site penalised — never buy links,
never post the same text in many places, never create fake accounts.

## Already done for you

- **IndexNow:** all 162 site URLs submitted to Bing (which also feeds DuckDuckGo
  and Copilot search). The pipeline re-notifies Bing after every future run.
- **GitHub:** the repository homepage, description and topics point at the live
  site, and the README links the main calculators. GitHub is a high-authority
  domain, so this is a real (if modest) discovery path.
- **Embed programme:** every calculator can be embedded by other sites with a
  credit link back — see the "For publishers" page on the live site. This is the
  most scalable legitimate backlink channel the site has.

## 2. Reddit (answer questions; do not start threads just to link)

Communities: r/gardening, r/lawncare, r/landscaping, r/DIY.
Build a little history first (a few helpful comments with no links), then use a
link only when someone asks "how much X do I need". Ready answers:

**Q: How much mulch for a 20x20 garden?**
"At 3 inches deep that's 400 sq ft × 0.25 ft = 100 cubic feet, so about
3.7 cubic yards, or 50 bags of 2 cu ft. If you're doing 2 inches it's about
2.5 yards. I use this calculator so I don't have to redo the maths for every
bed: https://huzaifamasood30.github.io/gardencalc/mulch-calculator/"

**Q: Gravel for a shed base — how much and what kind?**
"Go 4 inches deep with crushed stone that has fines in it (crusher run), not
pea gravel — pea gravel rolls and the shed will rock. For a 10×12 shed, make
the pad 12×14 so it extends a foot past the shed, and that's about 2.9 tons
at 4 inches. Full working here:
https://huzaifamasood30.github.io/gardencalc/how-much-gravel-do-i-need-for-a-shed-base/"

**Q: How much grass seed for overseeding?**
"Overseeding rate is roughly 2–4 lb per 1,000 sq ft (new lawns are 4–8 lb).
So a 5,000 sq ft lawn needs about 15–20 lb for overseeding. Rates by grass
type: https://huzaifamasood30.github.io/gardencalc/grass-seed-calculator/"

## What NOT to do

- No Fiverr/SEO-marketplace link packages, no comment spam, no forum profile
  link farms, no expired-domain tricks. These are the classic ways new sites
  earn a manual penalty that takes months to undo.
- No exact-match anchor text everywhere. Natural anchors ("this calculator",
  "GardenCalc", the bare URL) are what real links look like.

## Cadence that works

- Pinterest: 2–3 pins/day for two weeks, then 3–4/week.
- Reddit/Quora/forums: 2–3 genuine answers/week total.
- Directory submissions: one batch, once.
- Embed outreach: 5 emails/week.
- After 4–6 weeks, check Search Console: impressions should be climbing
  first; clicks follow as pages move from page 3–5 toward page 1–2.
